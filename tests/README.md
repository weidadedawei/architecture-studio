# 可复现的静态检查

运行环境：Python 3.10 或更新版本；只使用标准库，不需要安装依赖、启动服务器或连接网络。

在教程文件包根目录执行：

```bash
python3 tests/static_check.py --report reports/static-check-report.json
python3 -m unittest discover -s tests -p 'test_*.py' -v
```

第一条命令完成 13 组静态检查，并生成 JSON 报告。每组都会输出 `PASS` 或 `FAIL`；存在失败项时进程退出码为 `1`。`--root` 可以指定另一个完整文件包目录；不传时从脚本位置自动找到文件包根目录，与当前终端目录无关。

第二条命令运行 13 个回归测试。它们在临时目录独立生成小型合法项目和导出文件，再制造外部脚本、失效端点、越界路径、翻译类型错误、重复 ID、内嵌数据过期、破损 PNG、教学用敏感标记、失效 Draw.io 连接和外部 SVG 图片等负例。还会检查命令行失败退出码和 JSON 报告。测试结束后自动清理临时目录，不会修改教程中的图稿。

| 检查 | 验证内容 |
| --- | --- |
| `required_files` | 网页、默认项目、操作实例和四组导出文件存在且非空 |
| `embedded_project` | 网页内嵌 `editorData.book` 与默认项目 JSON 完全相同 |
| `project_structure` | 双图、项目格式、当前视图和语言字段有效 |
| `bilingual_text` | 中英文目录键一致、显示字段有翻译、文本与模块数组类型正确 |
| `unique_ids` | 每张图内节点、分区、连线和注释共用的 ID 空间无重复 |
| `endpoints` | 连线起终点引用节点或分区，端口方向与比例合法 |
| `geometry` | 数值有限，矩形、注释、路径点和标签坐标位于画布内 |
| `inline_icons` | 图标采用可解码的内嵌图片，节点引用的图标存在 |
| `offline_html` | 没有外部脚本、样式、图片资源和已知网络调用入口 |
| `svg_exports` | SVG 可解析，资源引用使用内嵌图片或内部片段 |
| `drawio_exports` | Draw.io 为未压缩的可编辑单元，父子和连接引用有效，无箭头装饰线具有合法端点坐标 |
| `png_exports` | PNG 签名、IHDR、导出尺寸和基本文件结构符合约定 |
| `redaction_scan` | 可发布文本中没有命中教学用敏感标记、账户编号、ARN、用户绝对路径和私钥模式 |

脱敏规则使用通用教学模式，业务特定标识需要由发布者在私有环境另行审查；不要把真实敏感词清单写入公开测试或示例。

静态检查不执行 JavaScript，不验证浏览器按钮、拖拽、下载、性能或线上服务。PNG 检查不进行 OCR，也不证明每个像素与 JSON 一致；文件包中的 PNG 应由对应 SVG 重新渲染并人工查看。脱敏检查只覆盖脚本中声明的模式，不能替代人工审查或通用秘密扫描。
